# Figure Pipeline

Use this reference when a task needs the full data-to-figure chain rather than a single plot command.

## Artifact Roles

- `source_data`: raw or authority input data.
- `processed_data`: cleaned, joined, filtered, or normalized data used by analysis.
- `statistical_output`: model results, tests, confidence intervals, uncertainty estimates, or summary statistics.
- `figure_ready_data`: the exact table consumed by plotting code.
- `plot_code`: script or notebook section that turns figure-ready data into outputs.
- `editable_figure`: SVG, PDF, EPS, or other vector/editable master generated by code.
- `preview_derivative`: PNG/JPEG or low-resolution output for inspection, README display, or sharing.
- `manual_layout_project`: Illustrator, Inkscape, PowerPoint, Affinity, or equivalent downstream layout file.
- `final_export`: target-specific TIFF/PDF/EPS/SVG used in Word, LaTeX, supplement, response letter, or submission.
- `manuscript_container`: Word, LaTeX, Quarto, Markdown, or submission package that references or embeds the figure.

## Standard Chain

```text
source_data
-> processing / statistics
-> figure_ready_data
-> plot_code
-> editable SVG or vector output
-> optional manual layout project
-> final export / preview derivatives
-> manuscript or submission container
-> archived provenance
```

## Boundaries

- Upstream data and statistics decide what can be claimed.
- Plot code decides the reproducible visual mapping.
- Manual layout may refine spacing, labels, and journal-compliant composition, but it should not silently change values or evidence.
- Final exports and embedded manuscript images are downstream derivatives, not proof that the upstream chain is complete.

## Common Failure Modes

- Drawing from a spreadsheet whose rows, filters, or units are not documented.
- Editing figure values manually in Illustrator or PowerPoint.
- Keeping only PNG exports and losing the code-generated SVG/PDF master.
- Updating the SVG but forgetting the Word/LaTeX manuscript still uses an older derivative.
- Changing figure style while accidentally changing axis scales, group labels, or statistical annotations.
